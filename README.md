Nature's Barn Farm Website

1. Project Overview

Nature's Barn Farm is a fictional South African agricultural business website developed as part of the WEDE5020 Web Development Portfolio of Evidence (PoE).

The website aims to establish an online presence for the farm by introducing the business, showcasing its agricultural products and services, displaying farm-related images and videos, and providing visitors with a way to make enquiries.

2. Website Pages

The website consists of five main HTML pages:

Home: Introduces Nature's Barn Farm and highlights its offerings.

About Us: Provides information about the farm, its mission and vision.

Services: Displays the agricultural products and services offered.

Gallery: Showcases farm animals, landscapes and farm-related videos.

Contact: Provides contact information, an enquiry form and an embedded Google Maps location.

3. Technologies Used

The following technologies were used to develop the website:

HTML5: Used to structure the website and organise its content.

CSS3: Used to style the website, create layouts and implement responsive design.

JavaScript: Used to add interactive functionality, animations and form validation.

4. Part 1: Website Development

The first development phase focused on creating the website's structure using HTML5.

The five pages were created with consistent navigation, headings, content sections and footer elements.

The website also includes metadata such as page titles and descriptions to provide information about each page.

5. Part 2: CSS Styling and Design

CSS3 was implemented to establish a consistent visual appearance across the website.

The design uses an agricultural-inspired colour scheme, including green, cream, white and earthy accents.

Styling features include:

Navigation bar and footer styling.

Hero section with background imagery.

Content and service cards.

Gallery layouts.

Styled buttons and hover effects.

Contact form styling.

Responsive layouts using CSS media queries.

Transitions and animations.

Reduced-motion support.

The main stylesheet is located in CSS/styles.css.

6. Part 3: JavaScript Functionality

JavaScript was introduced to improve the website's interactivity and user experience.

The implemented functionality includes:

Hero content entrance animation.

Scroll-reveal effects using the Intersection Observer API.

Automatic highlighting of the current navigation page.

Contact form validation.

Feedback messages for successful or invalid form submissions.

The JavaScript code is located in JS/script.js.

Note: The contact form currently performs client-side validation. It does not submit enquiries to a server or store them in a database.
